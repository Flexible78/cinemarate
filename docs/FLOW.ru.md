# CinemaRate: весь флоу с нуля

Документ-памятка: что это, как поднять с пустой машины, что проверять и как
объяснять на собеседовании. Ничего из списка не требует платного аккаунта.

## 1. Что это за проект

Одностраничное веб-приложение: собирает рейтинги фильмов и сериалов из
нескольких публичных источников в одну карточку, хранит общий список
«Избранное» в облаке (один список на два устройства - мой и жены), умеет
искать по фильтрам и подсказывать, что смотреть вечером.

Живой адрес: <https://cinemarate.vercel.app>
Код: <https://github.com/Flexible78/cinemarate>

## 2. Из чего состоит

```
index.html            весь UI, поиск, сборка карточки, избранное, темы
api/discover.js       прокси к TMDB: health / genres / imdb / search / discover
api/favorites.js      общий список в Vercel Blob (GET, POST, ?debug=1)
api/pick.js           выбор одного фильма на вечер (ИИ или локальная эвристика)
infra/                описание окружения Vercel в Terraform
scripts/              проверки, которые запускает и CI, и вы локально
.github/workflows/    CI на каждый push и pull request
docs/                 эта папка: инструкции и тезисы для защиты
```

Фронтенд статический: ни фреймворка, ни сборки. Всё, что требует секретов или
внешних вызовов, живёт в serverless-функциях.

## 3. Что понадобится

| Что | Зачем | Цена |
| --- | --- | --- |
| Node.js 20+ | локальный запуск и деплой | бесплатно |
| аккаунт GitHub | код, CI, автодеплой | бесплатно |
| аккаунт Vercel | хостинг, функции, Blob-хранилище | free tier |

## 4. Поднять с нуля

### 4.1 Код

```bash
git clone https://github.com/Flexible78/cinemarate.git
cd cinemarate
npm install
```

### 4.2 Ключ TMDB

Регистрация на themoviedb.org, затем *Settings* -> *API*. Подходит и v3 API
key, и v4 read access token: функция сама распознаёт JWT и отправляет его
заголовком `Authorization`, а обычный ключ - параметром запроса.

### 4.3 Локальный запуск

```bash
npx vercel dev
```

Открыть <http://localhost:3000>. Ключи для локальной работы кладут в
`.env.local` - этот файл в `.gitignore` и в репозиторий не попадёт:

```
TMDB_KEY=...
GROQ_API_KEY=...
```

Без `TMDB_KEY` не работает только панель подбора. Без Blob-хранилища избранное
живёт в браузере, и панель честно пишет «Local store».

### 4.4 Локальные проверки (те же, что в CI)

```bash
node --check api/favorites.js
node --check api/discover.js
node --check api/pick.js
node scripts/check-inline-js.mjs index.html
```

### 4.5 Первый деплой

```bash
npx vercel
```

Соглашаемся с настройками по умолчанию - получаем адрес `имя.vercel.app`.

### 4.6 Blob-хранилище для общего списка

В дашборде проекта: *Storage* -> *Create Database* -> *Blob* -> *Connect to
Project*. Доступ выдаётся через OIDC: Vercel сам подкладывает короткоживущий
токен в функцию, руками копировать нечего.

### 4.7 Переменные окружения

*Settings* -> *Environment Variables*, для Production, Preview и Development:

| Переменная | Обязательна | Что делает |
| --- | --- | --- |
| `TMDB_KEY` | для подбора | ключ TMDB, только на сервере |
| `FAVORITES_TOKEN` | нет | если задана, `/api/favorites` и `/api/pick` требуют секрет |
| `GROQ_API_KEY` | нет | ИИ-подбор через Groq (приоритетный провайдер) |
| `GROQ_MODEL` | нет | по умолчанию `llama-3.3-70b-versatile` |
| `MISTRAL_API_KEY` | нет | ИИ-подбор через Mistral, если нет ключа Groq |
| `MISTRAL_MODEL` | нет | по умолчанию `mistral-small-latest` |

После добавления переменных нужен новый деплой: `npx vercel --prod`.

### 4.8 Автодеплой из GitHub

```bash
gh repo create cinemarate --public --source=. --remote=origin --push
npx vercel git connect
```

Дальше push в `main` = production, каждый pull request = свой preview-адрес.

### 4.9 Проверка, что всё живо

| Проверка | Ожидаем |
| --- | --- |
| `/api/discover?mode=health` | `hasKey: true` |
| `/api/favorites?debug=1` | `hasStoreId: true` и успешная проба чтения |
| `/api/pick` (GET) | `ai`, `provider`, `model`, `engine` |
| панель избранного | «Shared store» и число записей |
| вкладка Actions | зелёный прогон CI |

### 4.10 Terraform (необязательно)

```bash
cd infra
export VERCEL_API_TOKEN=...
terraform init
terraform plan
```

`infra/README.md` - как принять уже существующий проект через
`terraform import`; `infra/MANUAL.md` - что пока делается руками и как
восстанавливаться после потери проекта.

## 5. Как работает общий список

Изначально клиент отправлял весь свой список и перезаписывал файл целиком:
два устройства = потерянные записи (классический lost update). Сейчас каждый
POST несёт не только элементы, но и `base` - ключи, которые браузер видел в
прошлый раз. Сервер сливает состояния: то, что появилось у другого устройства,
сохраняется, а удаление применяется только если ключ действительно был в базе
клиента. Плюс клиент раз в минуту (и при возврате на вкладку) подтягивает
серверное состояние.

## 6. Как работает ИИ-подбор

Подробно - в [AI_SETUP.ru.md](AI_SETUP.ru.md). Коротко: браузер отправляет в
`/api/pick` укороченный список (до 60 записей: название, год, тип, средний
балл), функция просит модель выбрать одну запись и объяснить в одну строку.
Ключ читается только внутри функции. Нет ключа или модель молчит дольше
8 секунд - отвечает локальная эвристика, формат ответа тот же.
