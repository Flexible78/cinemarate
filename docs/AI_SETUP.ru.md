# ИИ-подбор фильма: включить, проверить, не утечь

Кнопка «🎲 What do we watch tonight?» работает всегда. Без ключа выбор делает
локальный алгоритм (лучший средний балл со случайной поправкой). С ключом ту же
задачу решает внешняя модель и добавляет короткое обоснование.

## 1. Утечёт ли что-нибудь

Короткий ответ: код в репозитории и так публичный - это нормально и это плюс
для портфолио. Утекать может только то, что вы сами положите в код. Ключей в
коде нет.

- Ключ хранится в Environment Variables проекта Vercel. Он не попадает ни в
  git, ни в HTML, ни в JS, который грузит браузер.
- Браузер обращается только к вашему `/api/pick`. Запрос к модели уходит с
  сервера Vercel, где и читается ключ.
- Имя переменной специально без префиксов вида `NEXT_PUBLIC_` / `VITE_`:
  именно такие префиксы вшивают значение в клиентский бандл.
- CI роняет сборку, если в коммит попал `.env` или литерал, похожий на ключ.
- Жена ничего не вводит и ключа не видит: она просто нажимает кнопку, ключ
  остаётся на сервере. Один ключ обслуживает оба устройства.
- Что реально уходит провайдеру: до 60 строк вашего списка - название, год,
  тип, средний балл, категория. Ни почты, ни токенов, ни адресов.
- Если и этого не хочется - не задавайте ключ: кнопка продолжит работать на
  эвристике.
- Хотите закрыть эндпоинты от посторонних - задайте `FAVORITES_TOKEN`, тогда и
  список, и подбор требуют секрет (браузер запоминает его один раз из
  `?token=...`).

## 2. Вариант A: Groq - рекомендую

Быстрее всех (ответ за доли секунды), бесплатный tier без карты, дневных
лимитов для двух человек хватает с огромным запасом.

1. Открыть <https://console.groq.com> и зарегистрироваться через Google или
   GitHub.
2. Раздел *API Keys* -> *Create API Key*. Значение показывают один раз -
   скопировать сразу.
3. Vercel -> проект `cinemarate` -> *Settings* -> *Environment Variables* ->
   *Add*:
   - Name: `GROQ_API_KEY`
   - Value: скопированный ключ
   - Environments: Production, Preview, Development
   - *Save*
4. Передеплоить, иначе функция новую переменную не увидит:
   `npx vercel --prod` (или *Deployments* -> ... -> *Redeploy*).
5. Проверить: открыть `https://cinemarate.vercel.app/api/pick` в браузере.
   Ожидаем примерно:
   `{"ai":true,"provider":"groq","model":"llama-3.3-70b-versatile","engine":"groq/llama-3.3-70b-versatile"}`
6. Нажать кнопку на сайте: в ответе будет строка вида
   `engine: groq/llama-3.3-70b-versatile`.

Другую модель можно задать переменной `GROQ_MODEL`.

## 3. Вариант B: Mistral

1. Открыть <https://console.mistral.ai> и зарегистрироваться.
2. Выбрать бесплатный план (Experiment / Free). Обычно просят подтвердить
   номер телефона - карта не нужна.
3. *API Keys* -> *Create new key*, скопировать.
4. Vercel -> *Environment Variables* -> `MISTRAL_API_KEY` = ключ, те же три
   окружения.
5. `npx vercel --prod`, затем `/api/pick` должен показать
   `"provider":"mistral"`.

Модель по умолчанию `mistral-small-latest`, переопределяется `MISTRAL_MODEL`.

## 4. Если заданы оба ключа

Порядок предпочтения зашит в функции: сначала Groq, потом Mistral. Первый
найденный ключ и используется - удобно переключать провайдера, просто удалив
переменную.

## 5. Локально

```
# .env.local, файл в .gitignore
GROQ_API_KEY=...
```

Затем `npx vercel dev`.

## 6. Стоит ли поднимать модель локально

Для этого сайта - нет. Публичная страница на Vercel не может дотянуться до
модели на домашнем компьютере, если не держать его постоянно включённым и не
открывать наружу - а это как раз настоящий риск, в отличие от серверного
ключа. Локальная модель уместна для экспериментов, но в резюме интеграция
внешней модели с таймаутом, деградацией и валидацией ответа звучит сильнее,
чем «запускал модель на ноутбуке».

## 7. Что заложено против сюрпризов

- Таймаут 8 секунд на запрос к модели.
- Любая ошибка провайдера не отнимает у пользователя ответ: приходит
  `engine: "heuristic (ai unavailable)"` и поле `note` с причиной.
- В промпте прямо сказано: названия и заметки - это данные, а не инструкции
  (защита от prompt injection через собственный список).
- Ключ, который вернула модель, проверяется по отправленному списку; выдуманный
  ответ отбрасывается.
- В модель уходит максимум 60 записей и обрезанные строки - предсказуемая
  стоимость запроса.

## 8. Типичные ошибки в поле `note`

| Текст | Причина |
| --- | --- |
| `Invalid API Key` / `http_401` | ключ скопирован с пробелом или не тот проект |
| `http_429` | упёрлись в лимит, подождать или сменить провайдера |
| `model_not_found` / `http_404` | опечатка в `GROQ_MODEL` / `MISTRAL_MODEL` |
| `The operation was aborted` | провайдер не ответил за 8 секунд |
| `model returned an unknown key` | модель придумала запись, ответ отброшен |
